Markdown Core

Shared Markdown import, export, validation, and sanitization for Odoo 19

A lightweight technical addon that powers Markdown workflows in Automatify Knowledge Markdown and Social Publisher Markdown. It does not add Knowledge pages, Social Posts, menus, or external publishing integrations by itself.

Features

  • Convert portable Markdown to sanitized Odoo HTML.
  • Export Odoo HTML back to Markdown.
  • Preserve headings, emphasis, links, images, lists, blockquotes, tables, inline code, and fenced code blocks, including Mermaid language identifiers.
  • Validate UTF-8 .md and .markdown uploads and enforce a default 2 MiB file size limit.

Installation and consumers

Install on Odoo 19 with the Python dependency Markdown>=3.5,<4. This module provides reusable services and is installed automatically as a dependency of knowledge_markdown or automatify_social_markdown when those addons are selected.
