Features

  • OAuth 2.0 Authorization Code flow with PKCE S256.
  • Requests posting, media-upload, identity, and offline-refresh scopes.
  • Account identity resolution through the official X API.
  • Provider-safe text publishing through X API v2.
  • Single-image JPG, PNG, or WebP publishing through X API v2 chunked media upload.
  • Refresh-token support for scheduled publishing.
  • External X post link stored on the publication target.
  • Integration with core scheduling, retries, and per-channel publication status.
  • One-time, expiring OAuth state bound to the initiating Odoo user and account.

Setup

  1. Create or use your own X Developer App.
  2. Enable Read and write user authentication for the app.
  3. Open Social Marketing → Configuration → X Settings.
  4. Enter your own X Client ID and Client Secret when your app type uses one.
  5. Copy the OAuth Redirect URL displayed by Odoo into the exact Callback / Redirect URLs for your X app.
  6. Create an X Social Account in Odoo and choose Connect X.

The redirect URL is generated from the installation's standard Odoo web.base.url. No production callback URL, client credential, or OAuth token is bundled with this addon.
