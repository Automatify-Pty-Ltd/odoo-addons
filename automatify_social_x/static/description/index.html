Social Publisher X

X publishing for Social Publisher on Odoo 19 Community

Connect an X Developer App with OAuth 2.0 PKCE and publish text posts from the Social Publisher scheduling and retry workflow.

Features

  • OAuth 2.0 Authorization Code flow with PKCE S256.
  • Account identity resolution through the official X API.
  • Text post publishing through X API v2.
  • Refresh-token support for scheduled publishing.
  • Integration with core scheduling, retries, and per-channel publication status.
  • One-time, expiring OAuth state bound to the initiating Odoo user and account.
  • Actionable account health for rejected authorization.

Requirements and external service

Requires Social Publisher and an X Developer App owned or authorized by the installing organization. X controls API access, billing or usage credits, limits, pricing, and availability.

Client credentials and OAuth tokens are not bundled with this addon. The connector communicates directly with X's official OAuth and API endpoints.
