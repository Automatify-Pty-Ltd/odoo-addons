Social Publisher X

X publishing for Social Publisher on Odoo 19 Community

Connect an X Developer App with OAuth 2.0 PKCE, compose in Odoo, and publish provider-safe text with an optional image from the Social Publisher workflow.

Features

  • OAuth 2.0 Authorization Code flow with PKCE S256.
  • Requests posting, media-upload, identity, and offline-refresh scopes.
  • Account identity resolution through the official X API.
  • Provider-safe text publishing through X API v2.
  • Single-image JPG, PNG, or WebP publishing through X API v2 chunked media upload.
  • Refresh-token support for scheduled publishing.
  • External X post link stored on the publication target.
  • Integration with core scheduling, retries, and per-channel publication status.
  • One-time, expiring OAuth state bound to the initiating Odoo user and account.

Requirements and external service

Requires Social Publisher and an X Developer App owned or authorized by the installing organization. X controls API access, billing or usage credits, limits, pricing, and availability. Existing connections created without media.write must reconnect before image publishing.

Client credentials and OAuth tokens are not bundled with this addon. The connector communicates directly with X's official OAuth, media-upload, and Posts API endpoints. Post text and selected image bytes are sent to X only when publishing or when a scheduled post becomes due.
