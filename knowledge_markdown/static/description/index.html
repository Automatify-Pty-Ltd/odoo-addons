Knowledge Markdown

A self-contained Markdown knowledge workspace for Odoo 19

Create, edit, import, revise, and export knowledge pages without any third-party Knowledge addon dependency. Shared conversion comes from the lightweight Markdown Core addon.

Built and maintained as open source by Automatify Pty Ltd.

Highlights

  • No dependency on OCA document_page or document_knowledge.
  • Create categories and editable knowledge pages directly in Odoo.
  • Create a new page from a UTF-8 .md or .markdown file.
  • Import Markdown into an existing page as a new revision.
  • Export the current page to portable Markdown.
  • Keep fenced code languages, including mermaid.
  • Sanitize imported HTML and enforce normal Odoo access checks.
