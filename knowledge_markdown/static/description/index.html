Knowledge Markdown

Import and export OCA Knowledge pages as Markdown

Move documentation between Markdown files and Odoo 19 Knowledge while preserving headings, lists, links, tables, code blocks, and language identifiers such as Mermaid.

Built and maintained as open source by Automatify Pty Ltd.

Highlights

  • Import UTF-8 .md and .markdown files into existing Knowledge pages.
  • Export the current page to portable Markdown.
  • Keep fenced code languages, including mermaid.
  • Create a normal Knowledge revision on import.
  • Sanitize imported HTML and enforce normal Odoo access checks.
