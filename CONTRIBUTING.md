# Contributing

Thanks for contributing to Automatify Odoo Addons.

- Target the supported Odoo major version documented by the addon.
- Keep addons independent of private Automatify infrastructure and credentials.
- Add or update tests for behavior changes.
- Do not commit secrets, environment files, tokens, customer data, or deployment credentials.
- Use focused pull requests with a clear description and rollback impact.

Bug reports and feature requests are welcome through GitHub Issues.
