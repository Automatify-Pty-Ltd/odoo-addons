Open social publishing workflow for Odoo 19 Community

Compose social posts in Odoo with a native rich editor, attach an image, schedule or publish, track per-channel results, and extend the workflow with provider connectors.

Core features

  • Rich Odoo post authoring with provider-safe outbound text rendering.
  • One image attachment directly from the Social Post form.
  • Draft, scheduled, processing, published, failed, and cancelled states.
  • Publish now, future scheduling, retry failed channels, cancel, and reset to draft.
  • Distinct Scheduled At and Published At semantics.
  • Per-channel external post ID, network link, publication status, and error detail.
  • Five-minute scheduled publishing cron with bounded batches.
  • Per-account publication targets for multi-channel fan-out.
  • Company-aware record rules and cross-company target validation.
  • Odoo-native extension hooks for installed connector addons.

Open-source boundary

Baseline authoring and publishing UX is intentionally part of the open-source addon: rich authoring, image attachment, scheduling, retries, external links, and provider extension hooks. Advanced workflow, analytics, AI, governance, and campaign-scale features can be delivered separately without making this core a demo-only product.

External services

This core addon makes no external network requests and includes no provider credentials. Network-specific connector addons may communicate with official third-party APIs and require credentials supplied by the installing organization.
