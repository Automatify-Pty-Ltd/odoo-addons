Social Publisher Markdown

Turn Markdown files into reviewable social drafts

Create a new Social Publisher draft from Markdown or import Markdown into an existing editable post. Review the rendered result before publishing to installed connectors such as LinkedIn or X.

Highlights

  • UTF-8 .md and .markdown upload.
  • Sanitized rich-text rendering in the normal Social Post editor.
  • No automatic publishing after import.
  • Works with Social Publisher's existing scheduling and retry workflow.
  • Shared Markdown engine; no Knowledge app is required.
